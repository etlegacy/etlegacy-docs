Console Commands
^^^^^^^^^^^^^^^^

ETL exposes a large set of console commands. Most of them are available to
every player, some are restricted to server operators, referees and
shoutcasters. Commands are typed in the console, which is opened with the
``~`` key (``CONSOLE_KEY`` in the key bindings) or from the main menu.

The console supports the usual editing shortcuts: ``Up`` and ``Down`` browse the
command history, ``Tab`` completes the command and its arguments, and
``Ctrl`` + ``C`` copies the console content to the clipboard.

.. note::
   Commands are case insensitive, so ``MAP``, ``map`` and ``Map`` are equivalent.
   Most commands accept arguments, for example ``map oasis`` loads the
   ``oasis`` map on the server.
